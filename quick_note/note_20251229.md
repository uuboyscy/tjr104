1. Download images
   1. `docker pull <image_name>:<tag>`
   2. example: `docker pull python:3.11-slim-bullseye`
2. Show all docker images you downloaded
   1. `docker images`
3. Start a virtual machine via image
   1. `docker run ...`
   2. [Docker run example](https://docs.uuboyscy.dev/docs/Docker/docker-tutorial/Docker%20Commands#build-docker-container)
4. Interact with the VM (virtual machine)
   1. `docker exec ...`
   2. [Docker exec example](https://docs.uuboyscy.dev/docs/Docker/docker-tutorial/Docker%20Commands#manipulate-container)
   3. You will notice that your cursor changed
5. Exit the VM
   1. Press `Ctrl + D` to quit the session
6. Check VM status
   1. `docker ps` to check all running VM
   2. `docker ps -a` to check all VM include exited VM
7. Stop and release a VM
   1. `docker rm -f <docker container name>`
   2. `docker rm -f <docker container ID>`
