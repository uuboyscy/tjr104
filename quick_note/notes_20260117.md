## How to connect to a remote machine (Compute Engine)
1. Generate key pairs
   1. Public key
   2. Private key
2. Lock remote machine
   1. Create an authorized_keys in ~/.ssh
   2. Paste the content of public key in it
3. SSH connect to the remote machine
   1. `ssh -i <your private key>` <user_name>@<public_IP>
